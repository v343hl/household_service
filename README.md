

\# Household Service Order Processing System



\## Project Description

This project represents a database for managing the order processing system of a household service company.



\## Database Models



\### 1. Third Normal Form (3NF)

The relational database model consists of seven tables:

\- Clients

\- Employees

\- Services

\- Order Statuses

\- Orders

\- Order Items

\- Payments



\### 2. Data Vault

The Data Vault model consists of:

\- 7 Hub tables

\- 6 Link tables

\- 7 Satellite tables
